# kitoboy-pie

Сервис детекции персональных данных в тексте. Он является состамной частью системы [Kitoboy](https://github.com/psytechlab/kitoboy), но также может быть использован отдельно, например, для задачи анонимизации данных.

# Запуск сервера

```bash
$ fastapi run app/main.py --port 5900
```

## Запуск сервера через Docker

Для сборки докер-образа нужно выполнить команду
```
$ docker build -t kitoboy-pie:v1 .
```

После сборки запустите сервис командой
```
$ docker run -p5900:5900 kitoboy-pie:v1
```

# Информация об API

Сервер имитирует Triton Inference Server и реализует некоторые методы, необходимые для работы сервиса и интеграции его в другие системы.

- GET /v2 - отдает фиксированный объект с информацией об API
- GEY /v2/health/ready - отдает код 200, если сервер онлайн
- POST /v2/models/pie/infer - производит инференес. На вход ожидается список объектов Triton-сервера (см. пример ниже)
- GET /v2/models/pie/config - отдает информацию о настройке, главная из которых - максимальный размер батча.

# Пример входных данных
Обратите внимание, что нулевая размерность в `shape` равна количеству строк в `data`/

```json
{
    "inputs":
    [
        {
            "name":"text_input",
            "shape":[3,1],
            "datatype":"BYTES",
            "data":[ "+79099444970", "скиньте деньги на поесть 1111 1111 1111 1111 имя Никита", "помогите мне"]
        }
    ]
}

```

# Тестовый запрос
Подразумевая, что сервер запущен командой в точности из раздела "Запуск сервера", тестовый запрос выглядит так: 

```bash
$ curl -X POST http://localhost:5900/v2/models/pie/infer -H "Content-Type: application/json" -d '{"inputs":[{"name":"text_input","shape":[3,1],"datatype":"BYTES","data":["+79099444970", "скиньте деньги на поесть 1111 1111 1111 1111 имя Никита", "помогите мне"]}]}'
```

# Как добавить обработчик данных

1. Создайте класс, сделав его наслдеников класса `information_extractor.AbstractIE`.
2. Реализуйте метод `make_prediction`. Он принимает на вход строку для обработки `text` и возвращает список меток - найденные сушности.
3. Добавьте тест (хотя бы на один пример) обработчика в `test/test_main.py` по образцу других обработчиков.
3. Добавьте инициализацию класса в списк `app.state.ie_list` в файле `app/main.py`.
