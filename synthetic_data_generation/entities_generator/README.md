# Entities Generator

Модуль генерации и отбора пулов PII-сущностей.

## Структура

- `notebooks/` - ноутбуки генерации сущностей.
- `organizations_extraction/` - эксперименты по извлечению организаций из внешнего датасета вакансий.
- `outputs/` - рабочие и промежуточные результаты генерации. Не коммитится.
- `outputs/history/` - история промежуточных прогонов. Не коммитится.

## Рабочий процесс

1. Сгенерировать или извлечь кандидаты в `outputs/`.
2. Просмотреть и почистить пул.
3. Если пул устраивает, вручную перенести финальный файл в `synthetic_data_generation/data/entities_pool/` или во внешнее хранилище команды.

Ноутбуки запускаются из папки `notebooks/`.
