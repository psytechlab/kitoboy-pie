# Synthetic Data Generation

Эксперименты по генерации синтетических текстов с PII-разметкой.

## Структура

- `configs/` - общие промпты и настройки для генераторов и синтезатора.
- `data/` - локальные входные данные: корпус текстов и финальные пулы сущностей. Крупные файлы не коммитятся.
- `corpus_analysis/` - анализ и маршрутизация корпуса текстов.
- `entities_generator/` - генерация и отбор пулов PII-сущностей.
- `synthesizer_agent/` - синтезатор текстов с PII-сущностями и метрики качества.

## Важное про данные

Файлы `*.csv`, `*.json`, `*.jsonl`, `*.xlsx`, `*.parquet`, `*.tar`, `*.zip` игнорируются git. Если для запуска нужны корпуса или готовые пулы, их нужно положить локально в ожидаемые папки.

Ноутбуки запускаются из своих папок, поэтому пути внутри них относительные к папке ноутбука.
