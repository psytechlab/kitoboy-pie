# PII Detector

Модуль regex-based извлечения PII-сущностей.

## Структура

- `src/enitites_regex_extractor.py` - основной скрипт для извлечения сущностей по YAML-конфигам.
- `configs/` - YAML-конфиги групп PII-сущностей: регулярные выражения, контекстные слова, параметры проверок.
- `data/examples.yaml` - примеры текстов для быстрого smoke-test запуска экстрактора.
- `data/` - небольшие справочные файлы и локальные данные для детектора, если нужны.
- `info/` - заметки, отчеты по конфликтам и вспомогательная информация.

## Быстрая проверка

Из корня репозитория:

```bash
uv run python PII_detector/src/enitites_regex_extractor.py
```

Скрипт сам ищет `configs/` и `data/examples.yaml` относительно папки `PII_detector`.
