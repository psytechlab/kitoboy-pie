# Organizations Extraction

Эксперименты по сбору пула организаций из внешнего датасета вакансий.

Ожидаемые локальные файлы:

- `Raw_Jobs.csv` - сырой датасет вакансий.
- `companies.csv` - промежуточный список компаний.
- `companies_filtered.csv` - отфильтрованный список компаний.

CSV-файлы не хранятся в git из-за размера. Ноутбук `org_test.ipynb` можно использовать для анализа и ручного отбора организаций.
