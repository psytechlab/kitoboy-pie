# Corpus Analysis

Ноутбуки для анализа и предварительной маршрутизации корпуса текстов.

- `corpus_analysis.ipynb` - базовый анализ корпуса.
- `corpus_router.ipynb` - эксперименты с классификацией текстов по категориям, подходящим для вставки PII.
- `outputs/` - локальные результаты анализа и разметки. Не коммитится.

Ноутбуки запускаются из этой папки.
