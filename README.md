# Kitoboy PII

Репозиторий с экспериментами и инструментами для работы с PII-сущностями в текстах.

Основные части проекта:

- `PII_detector/` - regex-based детектор PII-сущностей и связанные конфиги.
- `synthetic_data_generation/` - пайплайн генерации синтетических PII-сущностей и текстов с разметкой.

## Данные

Крупные данные не хранятся в git:

- корпуса текстов;
- сырые CSV-датасеты;
- сгенерированные JSON/JSONL-результаты;
- промежуточные пулы сущностей.

Такие файлы лежат локально или во внешнем хранилище команды. Перед запуском ноутбуков их нужно положить в соответствующие папки, описанные в README внутри модулей.

## Запуск ноутбуков

Ноутбуки запускаются из своих папок. Пути внутри ноутбуков указаны относительно папки, где лежит конкретный ноутбук.
