# Data

Локальные данные для синтетической генерации.

Ожидаемые файлы:

- `corpus.csv` - основной корпус текстов.
- `texts_200_500_symbols.csv` - подготовленный корпус коротких текстов для синтезатора.
- `entities_pool/` - финальные утвержденные пулы сущностей, которые использует синтезатор.

Эти данные не коммитятся в git. Их нужно брать из внешнего хранилища команды или генерировать локально.
