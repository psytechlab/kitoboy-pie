# Entities Pool

Папка для финальных утвержденных пулов сущностей, которые читает синтезатор.

Ожидаемый формат: один JSON-файл на тип сущности, например:

- `NAME.json`
- `ADDRESS.json`
- `ORGANIZATION.json`
- `EMAIL.json`

Сами JSON-файлы не хранятся в git. После генерации и ручной проверки пул нужно положить сюда локально.
